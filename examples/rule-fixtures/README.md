# Rule fixtures

Small Remotion films that each show one problem a rule should report, next to a fixed version that it shouldn't. They're used to check rules when they're added or changed.

| Rule                    | Shows the problem                                                                                                                            | Fixed                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `layout/tight-spacing`  | `TightSpacing`: a 48 px heading 23 px above a code panel, and a padded chat bubble 12 px above a command line                                | `TightSpacingFixed`. Both have a headline cut off by its window, whose hidden part ends 11 px from the next window: it is measured by what is visible, so it isn't reported                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `layout/text-overlap`   | `BriefOverlap`: one caption replaces another with both fully drawn for one frame. `BriefOverlapFaded`: the same, with the old caption at 69% | `BriefOverlapFixed`, and `BriefOverlapCrossfade`, a two-frame crossfade at 45%                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `staging/empty-surface` | `EmptySurface`: a large panel with its three lines of content in the top-left corner                                                         | `EmptySurfaceFixed`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `staging/small-focus`   | `SmallFocus`: a request in a chat bubble, about 2% of the canvas, read in a wide shot of a large window                                      | `SmallFocusFixed` pushes in on the bubble. `SmallFocusReread`: the request is read while pushed in and comes back in a wide shot. `SmallFocusLinger`: a status line read while pushed in, then the camera pulls back. `SmallFocusRelease`: a longer status line the camera pulls back from before it is read. `SmallFocusCollapse`: a request partly read during a push, while a sidebar pulls the eye away, comes back into view after a list above it collapses. `SmallFocusLinked`: a finding with a leader line, drawn in a canvas-sized svg, to a marker. `SmallFocusEdgeLinked`: the same, with the line starting at the pane's edge level with the finding (`SmallFocusEdge`, without the line, is reported) |
| `cursor/covers-text`    | `CursorOnText`: the cursor clicks a button and stays on its label                                                                            | `CursorOnTextFixed`, which moves it aside                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `layout/text-cut`       | `CutText`: a button label with its last letter cut off, a paragraph cut through its last line, and a sliver of a list row at a window's edge | `CutTextFixed`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

```bash
npm run build                 # in the repository root, once
cd examples/rule-fixtures && npm install
npm test                      # each rule reports its film and not the fixed one
npx mographc lint TightSpacing  # the findings for one film
```
